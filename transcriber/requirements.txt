# Transcriber: speaker diarization + fused audio/text emotion.
#
# Core
faster-whisper>=1.0.0         # transcription (CTranslate2; ~4x faster than
                              # openai-whisper on CPU, built-in VAD, int8)
soundfile>=0.12.0             # WAV I/O
numpy>=1.24.0
streamlit>=1.30.0             # GUI (optional if you only use the CLI)

# Emotion (audio wav2vec2 + text RoBERTa via Hugging Face). transformers needs
# a backend; torch powers both pipelines (and CUDA autodetect for speed).
transformers>=4.38.0
torch>=2.1.0

# Diarization backend: offline clustering (default, no token needed).
# Resemblyzer also produces the voiceprints used to recognise speakers across
# recordings, and the speaker store itself is stdlib sqlite3 -- no extra deps.
resemblyzer>=0.1.1            # speaker embeddings
scikit-learn>=1.2.0           # clustering + silhouette auto speaker count

# Diarization backend: pyannote (optional, best quality, needs an HF token).
# Uncomment to enable:
# pyannote.audio>=3.1.0
#
# Tests (development only -- not needed to run the transcriber):
#   pip install pytest
# then: python -m pytest transcriber/tests -q
#
# System dependency (not pip-installable): ffmpeg must be on PATH.
#
# macOS note: ctranslate2 (faster-whisper) and torch each bundle their own copy
# of libiomp5, which aborts the process when both load. transcriber/runtime.py
# sets KMP_DUPLICATE_LIB_OK before either imports. On Apple Silicon, install a
# native arm64 Python -- Rosetta x86 wheels are slow and make this worse.
# See the Troubleshooting section of transcriber/README.md.
#
# Speed tips: with a CUDA GPU, faster-whisper and the emotion models switch to
# float16 automatically. Use --model distil-large-v3 for the fastest accurate
# transcription, or a smaller size (tiny/base) on CPU.
