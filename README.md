# Daily Device Usage Tracker

Track how you spend your day across your Apple devices — MacBook, iPhone, iPad, and Apple Watch.

## Features

- **24-hour timeline** — visual breakdown of device usage across the day, color-coded by activity
- **Manual time-block logging** — select device, activity category, start/end time, and optional notes
- **Activity categories** — Work, Browsing, Social Media, Communication, Entertainment, Fitness, Reading, Creative, Gaming, Other
- **Apple Watch health rings** — log Move (calories), Exercise (minutes), Stand (hours), and Steps with customizable goals
- **Daily summary cards** — total screen time per device and overall
- **Activity breakdown bars** — see which activities took the most time
- **Date navigation** — browse previous days with arrow buttons or keyboard left/right
- **Persistent storage** — all data saved to localStorage

## How to Use

1. Open `index.html` in your web browser
2. Use the date picker to select a day (defaults to today)
3. Scroll down to **Log Device Usage** and add time blocks
4. Fill in your Apple Watch activity data in the **Apple Watch Activity** section
5. Review your day in the timeline and summary sections

### Keyboard Shortcuts

- **Left/Right arrows**: Navigate between days (when not focused on an input)

## Files

- `index.html` — App structure and layout
- `styles.css` — Apple-inspired styling
